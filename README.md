# End-to-End Spark Iceberg Pipeline (2026 Modernization)

This project implements a scalable data platform that handles both batch and streaming transformations using PySpark and **Apache Iceberg**. 

## 2026 Updates
- **Zero-ETL Architecture:** Migrated from Delta Lake to Apache Iceberg for universal open table format compatibility.
- **AI-Driven Unstructured Processing:** Integrated Ollama (Gemma) via DSPy directly into the PySpark pipeline to parse and structure raw text logs on the fly.
